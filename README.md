# SecureScan

A secure and efficient **Node.js + Express.js backend** for the SecureScan Web Application Security Scanner.

## 🚀 Features

* User Registration & Login
* JWT Authentication
* Password Encryption using bcrypt
* Website Security Scan API
* Scan History Management
* MySQL Database Integration
* Sequelize ORM
* RESTful API Architecture
* CORS & Helmet Security
* File Upload Support
* Environment Variable Configuration

## 🛠️ Tech Stack

* Node.js
* Express.js
* MySQL
* Sequelize
* JWT
* bcryptjs
* Multer
* Helmet
* CORS
* Morgan
